# OpenAgent Infrastructure — v0.2.0-alpha.5 Release Notes (Proposal)

> - **Release Status**: Alpha Pre-release (Preview / Experimental)
> - **Target Audience**: Early adopters, security researchers, and toolchain testers.
> - **Production Warning**: This pre-release is strictly intended for testing and evaluation. It is NOT approved for production workloads.
> - **Supported Platform**: Linux x86_64 (`x64`) ONLY. Windows and macOS are unvalidated and not supported in this pre-release.

---

## 1. Overview & Improvement Summary

OpenAgent Infrastructure `v0.2.0-alpha.5` incorporates post-release audit remediations identified during the independent verification of `v0.2.0-alpha.4`:

1. **CLI Version Flag Handling**: Added support for standard `--version`, `-v`, and `version` commands in `openagent` CLI, ensuring automated toolchains and users can reliably query runtime versions without triggering help fallback.
2. **Cryptographic Release Verification Documentation**: Formally documents the independent verification procedures for Cosign keyless signatures and SLSA v1 build provenance attestations generated by the release pipeline.
3. **Cross-Platform Architecture Preparation**: Establishes technical specifications for extending deterministic desktop packaging to Windows x86_64 and macOS (Apple Silicon / Intel).

## 4. Known Limitations & Platform Roadmap

- **Current Platform Support**: Linux x86_64 is the sole verified distribution platform.
- **Windows x86_64**: Packaging requires Electron Windows zip scaffolding and `.exe` launcher adaptation; pending Windows CI runner integration.
- **macOS Apple Silicon & Intel**: Packaging requires `.app` bundle structure, code signing entitlements, and notarization pipeline; pending macOS CI runner integration.
