# OpenAgent Infrastructure v0.1.0-rc1 Release Notes

**Release Tag**: `v0.1.0-rc1`  
**Target Architecture**: Linux x64 (`x86_64`)

**License**: Apache-2.0

---

## 1. Overview

OpenAgent Infrastructure v0.1.0-rc1 represents the first public release candidate of the foundational open-source platform for policy-controlled autonomous AI agents. The platform executes entirely locally without cloud tracking or external telemetry, enforcing deterministic security boundaries across all agent interactions.

---

## 2. Implemented Subsystems & Features

- **Deterministic Policy Engine**: Full evaluation pipeline enforcing strict schema validation, domain whitelists/blacklists, and fail-closed default-deny fallback.
- **Local AI Agent Runtime**: Supervised execution loop with action metadata validation, token-bound execution dispatchers, emergency kill-switch, and user approval workflows.
- **Controlled Browser Agent**: Protocol-constrained browser interactions (`https:`, `http:` only; blocks dangerous schemes), DOM interaction guards, and full audit trail generation.
- **Tamper-Evident Audit & Replay**: Append-only SHA-256 hash chains, monotonic sequence counters, secret redaction, and deterministic session replay engine.
- **Lightweight Hybrid Vector Engine**: In-memory dense cosine vector indexing + sparse BM25 keyword matching with Reciprocal Rank Fusion (RRF) and transactional disk storage.
- **Knowledge Graph & Graph RAG**: Deterministic entity resolution, depth-bounded graph traversal, adjacency indexing, cycle protection, and grounded citation generation.
- **Decentralized Agent Network**: Cryptographic Ed25519 identity, wire pre-image signature authentication, replay-resistant nonce windows, and local reputation management.
- **Desktop Application**: Electron-based cross-platform GUI with sandboxed renderer, typed Preload IPC dispatchers, and encrypted local Credential Vault (AES-256-GCM).

## 5. Installation & Verification Instructions

### 1. Verify Checksum

```bash
sha256sum -c openagent-desktop-linux-x64.tar.gz.sha256
```

### 2. Extract Archive

```bash
tar -xzf openagent-desktop-linux-x64.tar.gz
cd openagent-desktop
```

### 3. Launch Application

```bash
./launch-openagent.sh
```

## 6. Platform Support Gating & Known Limitations

1. **Linux x64 (`x86_64`)**: Fully verified, tested, and passing all 10 E2E integration workflows, 7 failure scenarios, and 15 security regression suites.
2. **Windows x64**: **Untested / NOT RUN**. Source code is architecturally cross-platform, but binaries are blocked pending Windows CI runners and Authenticode signing credentials.
3. **macOS (arm64 & x64)**: **Untested / NOT RUN**. Blocked pending Apple Silicon CI hardware and Apple Developer ID notarization pipelines.
4. **Local Network Peer Discovery**: Operates over local loopback and subnet broadcast; NAT-traversal relaying is experimental and planned for v0.2.0.
