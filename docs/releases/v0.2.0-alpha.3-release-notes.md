## 1. Overview & Remediation Summary

OpenAgent Infrastructure `v0.2.0-alpha.3` resolves the release pipeline format gate failure encountered during the previous `v0.2.0-alpha.2` workflow execution (run `37942245642`), where unformatted historical markdown documents and unformatted SBOM generator outputs caused `npm run format:check` to halt the build process.

This candidate preserves all supply-chain hardening milestones introduced in `alpha.2` while making toolchain formatting deterministic and self-consistent.

### Key Changes in v0.2.0-alpha.3

1. **Format Gate Remediation**:
   - Normalized formatting across 9 historical markdown documents in `docs/releases/` and `docs/security-audit/` to eliminate Prettier style warnings (list markers, table alignments, spacing).
   - Ensured all 237 tracked repository source, documentation, and configuration files pass `npm run format:check`.

2. **Deterministic SBOM Formatting**:
   - Updated `scripts/generate-sbom.mjs` to format generated `sbom.cyclonedx.json` and `sbom.spdx.json` files asynchronously through Prettier (`prettier.format`) using the repository's `.prettierrc` configuration.
   - Enforced trailing newlines and standard array layouts, preventing newly generated SBOM files from violating formatting gates.

3. **Benchmark Script Output Hardening**:
   - Hardened `scripts/run-benchmarks.mjs` to format generated benchmark documentation (`docs/validation/benchmark-results.md`) through Prettier before persisting to disk.
   - Added support for `--no-write` flag and `PERSIST_BENCHMARKS=false` environment variable to allow running performance benchmarks without modifying the git working tree.

4. **Supply-Chain Verification Test Suite Updates**:
   - Updated `tests/supply-chain/supply-chain-policy.test.mjs` to await asynchronous SBOM generation cleanly.

## 2. Supply-Chain Hardening Architecture

This candidate maintains the complete supply-chain security architecture:

1. **Deterministic Linux Desktop Archive Packaging**:
   - Built using GNU tar with sorted filenames (`--sort=name`), normalized timestamps (`--mtime`), fixed numeric root ownership (`--owner=0 --group=0 --numeric-owner`), and uncompressed gzip timestamps (`gzip -n`).
   - Generates reproducible Linux desktop tarball archive: `openagent-desktop-linux-x64.tar.gz`.

2. **Standards-Compliant SBOM VCS Metadata**:
   - Generates CycloneDX 1.5 JSON and SPDX 2.3 JSON manifests embedding Git commit, repository URL, and release tag metadata.

3. **Isolated Two-Stage GitHub Actions Workflow**:
   - Job 1 (`build-and-package`): Read-only repository access (`contents: read`), running mandatory formatting, builds, unit tests, security tests, benchmarks, packaging, and SBOM generation.
   - Job 2 (`provenance-and-release`): Downstream job running with elevated permissions (`id-token: write`, `attestations: write`, `contents: write`) to perform checksum verification, SLSA build provenance attestation, Cosign blob signing, and GitHub release creation.

## 4. Known Limitations & Scope Boundaries

- **Platform Scope**: Linux x86_64 (`x64`) is the ONLY verified distribution platform. Windows and macOS distributions are **UNTESTED / NOT RUN** and not provided.
- **External Schema Validator Availability**: Formal external CLI schema validators (`cyclonedx-cli`, `check-jsonschema`, `osv-scanner`) are not installed on the build environment. SBOM validity was verified via internal programmatic JSON structural assertions.
- **Pre-Release Publication**: SLSA build provenance attestations and Sigstore Cosign signatures are generated by GitHub Actions upon authorized tag push and are not pre-packaged inside the source repository.

## 6. Verification & Installation Instructions (Linux x86_64)

### Verification

```bash
# Checksum verification
sha256sum -c SHA256SUMS

# Build provenance attestation (requires GitHub CLI 2.49.0+ once published)
gh attestation verify openagent-desktop-linux-x64.tar.gz \
  --repo Baby-Angel404/Open-Agent

# Cosign signature verification (requires Cosign 2.x+ once published)
cosign verify-blob openagent-desktop-linux-x64.tar.gz \
  --bundle openagent-desktop-linux-x64.tar.gz.bundle \
  --certificate-identity-regexp "^https://github.com/Baby-Angel404/Open-Agent/.github/workflows/release.yml@refs/tags/v.*" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com"
```

### Unprivileged Installation

Extract into a user-owned directory without superuser privileges:

```bash
mkdir -p ~/opt/openagent
tar -xzf openagent-desktop-linux-x64.tar.gz -C ~/opt/openagent
cd ~/opt/openagent/openagent-desktop
./launch-openagent.sh
```
