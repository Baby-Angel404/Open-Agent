## 1. Overview & Supply-Chain Hardening Milestones

OpenAgent Infrastructure `v0.2.0-alpha.2` builds directly on the runtime modernization baseline of `v0.2.0-alpha.1` (Node.js 22 LTS, Electron 41.10.7 Modern LTS) and introduces a software supply-chain hardening architecture.

### Key Milestones in v0.2.0-alpha.2

1. **Deterministic Archive Packaging**:
   - Desktop packaging (`apps/desktop/scripts/package.js`) now uses GNU tar with sorted directory traversal (`--sort=name`), normalized modification timestamps (`--mtime`), fixed root ownership (`--owner=0 --group=0 --numeric-owner`), and uncompressed gzip timestamps (`gzip -n`) executed under `set -o pipefail`.
   - Produces reproducible tarball archives across identical source trees.

2. **Standards-Compliant SBOM VCS Metadata**:
   - SBOM generation (`scripts/generate-sbom.mjs`) parses and validates 40-character hexadecimal Git commit hashes in strict mode.
   - Injects VCS repository URL, commit hash, build source revision, and release tag into CycloneDX 1.5 properties (`openagent:vcs:*`) and SPDX 2.3 `sourceInfo` / `PackageDownloadLocation`.

3. **Least-Privilege CI/CD Release Pipeline**:
   - Release workflow (`.github/workflows/release.yml`) splits into two isolated jobs:
     - `build-and-package`: Scoped strictly to read-only repository permissions (`contents: read`).
     - `provenance-and-release`: Only runs upon build success; scoped to `id-token: write`, `attestations: write`, and `contents: write`.
   - Third-party GitHub Actions are pinned to immutable commit SHAs.

4. **Cryptographic Build Provenance & Signing**:
   - Generates SLSA Build Level 2 build provenance attestations via `actions/attest-build-provenance` bound to the repository OIDC identity.
   - Signs the release tarball using Sigstore Cosign keyless blob signing (`cosign sign-blob`), generating an independent verification bundle (`.tar.gz.bundle`).

5. **Release Gate Defense-in-Depth**:
   - Enforces intermediate artifact checksum verification (`sha256sum -c SHA256SUMS`) in the downstream release job prior to signing or attestation.
   - Mandates explicit, non-empty release notes for the target tag (`docs/releases/${TAG}-release-notes.md`), eliminating silent fallbacks to historical release notes.

## 3. Verification Instructions (Linux x86_64)

### Method 1: SHA-256 Checksum Verification

```bash
sha256sum -c SHA256SUMS
```

Ensure `openagent-desktop-linux-x64.tar.gz: OK` is reported.

### Method 2: GitHub Artifact Attestation Verification

Verify build provenance against the authentic GitHub repository using the GitHub CLI (`gh` 2.49.0+):

```bash
gh attestation verify openagent-desktop-linux-x64.tar.gz \
  --repo Baby-Angel404/Open-Agent
```

Expected output confirms the artifact was built on GitHub Actions from the authentic repository and release tag.

### Method 3: Sigstore / Cosign Signature Verification

Verify the cryptographic signature using Cosign (2.x+):

```bash
cosign verify-blob openagent-desktop-linux-x64.tar.gz \
  --bundle openagent-desktop-linux-x64.tar.gz.bundle \
  --certificate-identity-regexp "^https://github.com/Baby-Angel404/Open-Agent/.github/workflows/release.yml@refs/tags/v.*" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com"
```

## 4. Unprivileged Installation and Execution

Extract into a user-owned directory without superuser privileges:

```bash
mkdir -p ~/opt/openagent
tar -xzf openagent-desktop-linux-x64.tar.gz -C ~/opt/openagent
cd ~/opt/openagent/openagent-desktop
./launch-openagent.sh
```
