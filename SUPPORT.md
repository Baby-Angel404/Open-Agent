# Getting Support for OpenAgent Infrastructure

We welcome users, researchers, and developers building with OpenAgent Infrastructure. Here is how to find help, report issues, and participate in community discussions.

## Channels

- **GitHub Discussions**: For general architecture questions, RFCs, feature ideas, and implementation advice, open a thread on [GitHub Discussions](https://github.com/openagent/openagent/discussions).
- **GitHub Issues**: For verified bugs, test failures, or reproducible runtime errors, search existing issues or open a new [Bug Report](https://github.com/openagent/openagent/issues/new/choose).
- **Security Inquiries**: For security advisories or vulnerability reports, follow the confidential procedure documented in [SECURITY.md](SECURITY.md).

## What to Include in Support Requests

When reporting an issue, please provide:

1. Operating system and CPU architecture (`uname -a`).
2. Node.js version (`node -v`).
3. OpenAgent commit SHA or release version.
4. Minimal reproducible test case or steps to reproduce.
5. Relevant audit logs (ensure all secrets/tokens are sanitized or redacted).
